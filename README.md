# Personal admin: gedeeld geheugen

Privé-repo waarmee Claude en ChatGPT hetzelfde weten over het project **Personal admin**. Chatgeschiedenis wordt niet gesynchroniseerd; deze bestanden wel.

- `AGENTS.md`: regels voor elke assistent (lees eerst)
- `docs/CONTEXT.md`: vaste kennis (mensen, systemen, regels, werkwijzen)
- `docs/HANDOFF.md`: waar we nu staan en wat de volgende sessie doet
- `docs/changes/`: één bestand per wijziging of beslissing (`TEMPLATE.md`)
- `CHANGELOG.md`: korte regel per wijziging, nieuwste boven
